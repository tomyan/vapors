# The racer's 60 s run with F0, 2026-11-14 (F0 acceptance)

One-scene row F0 is accepted when P0's run shows frame 0 under 16.7 ms
cold and warm on the dev machine (`docs/plans/one-scene.md`, section 4).
This is that run on main at 06b0c94, which holds F0's three PRs (#272,
#281, #303) and everything merged since. The run itself is unchanged
from P0's (`docs/perf/scene-run-2026-11-13.md`): 3,750 frames of the
racer's scripted drive, every frame judged from the first with no
warmup (D7 (a)), a frame over budget when its time from the start of
`App::frame` to the return of the GPU wait after it is over 16.7 ms
(D6 (a)).

## Setup

- Release build at 06b0c94. Every run prints `06b0c9449c6d`, with no
  `-dirty` suffix; the binary's sha256 is in
  `scene-run-f0-2026-11-14/sha256.txt`.
- The dev machine: Intel UHD 630 (CML GT2), Mesa 25.0.7 ANV, Vulkan,
  headless, rendering to an offscreen texture with no present. Scale 1,
  1100 x 720.
- Command: `cargo xtask quiet 30 -- scripts/scene-runs.sh
  docs/perf/scene-run-f0-2026-11-14 racer`, queued by a retry loop every
  10 minutes; the first attempt (13:28) held. The quiet lock held every
  xtask ci, test and gate run, and the script waited 271 s for the
  1-minute load to fall under 1.5. Three pairs, each a cold run on a new,
  empty `MESA_SHADER_CACHE_DIR` and a warm run on the cache it filled;
  each run's output is kept verbatim in `scene-run-f0-2026-11-14/`, and
  the tables are `scripts/scene-run-table.sh` on those files.
- The 1-minute load was 0.71 to 1.41 across the runs. The 5- and
  15-minute averages were 9.46 and 13.83 at the start and 5.80 and 11.74
  at the end: the machine had been busy before the window.

## Result

Every run exits 0: no frame over budget in any of the six, frame 0
included. F0 is accepted. Frame 0 took 6.2 to 6.5 ms to idle cold and
6.6 to 6.7 ms warm, against about 98 ms and 22 ms in P0's run.

The work F0 moved out of the judged frames is now `App::start`, before
frame 0 and not judged, printed by each run: 104.5 to 106.9 ms cold and
17.3 to 17.9 ms warm. It is moved, not reduced (Tom, 2026-11-13: a
vapors-owned pipeline cache waits until after this iteration).
