# FlexInsert with the flex lane (2026-11-14, layout-lane PR 3f-2)

`--scaling FlexInsert` is `Insert` on the flex-column list
(`crates/perf/src/rows_list.rs`, the elements tests'
`support/flex_list.rs`): body is a flex column of block rows, each
holding its text, with a vertical margin. It alternates a row inserted
before the middle row and that row removed. PR 3f-2 lays the column out
by its flex lane (`docs/plans/splice-layout.md`, section 10).

Method: `vapors-perf 60 10 --scaling FlexInsert`, release, Intel UHD 630
(ANV), 640 x 400, scale 1, median instructions per frame, one run, load
about 26 to 56 (instruction counts do not move with load). The branch is
3f-2's working tree on 3f-1 (5b30dab0).

| phase | kind | 1000 rows | 3000 rows | 10,000 rows | per extra row, 3000 to 10,000 |
|---|---|---|---|---|---|
| layout | insert | 714,189 | 1,923,875 | 6,152,511 | 604.1 |
| layout | remove | 676,268 | 1,888,336 | 6,122,634 | 604.9 |
| style | insert | 98,247 | 99,227 | 99,320 | 0.0 |
| style | remove | 8,116 | 8,116 | 8,125 | 0.0 |
| paint | insert | 2,844,756 | 8,436,871 | 28,365,413 | 2,846.9 |
| accessibility | insert | 1,858,350 | 5,396,550 | 18,203,512 | 1,829.6 |
| accessibility | remove | 1,859,972 | 5,410,413 | 18,240,915 | 1,832.9 |
| update | insert | 3,776,384 | 10,750,149 | 35,585,872 | 3,548.0 |
| frame (CPU) | insert | 5,817,163 | 16,328,076 | 53,970,904 | 5,377.5 |

The layout calls of an insert, a remove and a resize in a flex column
are the same at 50 and 500 rows (`crates/elements/tests/lane_flex.rs`).
The `layout` phase still grows by about 605 instructions per row: its
span (`update.rs`) also covers `stackings`, `ChangedSlots::of` and
`painted_from`, the placement of the rows the insert moved, and the
lane writes each later row's start (`write_starts`). How the 605 splits
between those is not measured here; PR 4 (derived positions) removes the
writes and the placement of moved rows. No count of this workload
without the flex lane was taken.

The judge holds `accessibility` to 1900 instructions per extra row
(`FLEX_INSERT_A11Y_PER_ROW`, from this run) and `style` flat, as for
`Insert`.
